# うつし窓

Windows PC と iPhone・iPad の間で、画面をブラウザにリアルタイム表示する GitHub Pages 用サイトです。一度に1対1で接続します。逆方向に映すときは、接続を終了して2台の役割を入れ替えます。

## GitHub Pages に置く

1. ZIPを展開します。
2. GitHubでリポジトリを作り、`index.html` をリポジトリ直下にアップロードします。公開済みの場合は、同じ場所の `index.html` を上書きします。公開が反映されたら、送る端末と見る端末の両方で再読み込みし、新しく招待を作ってください。画面表示、接続、QR生成に必要なコードはすべてこのHTMLに含まれています。新規リポジトリには、同梱の `.nojekyll` も置けます。
3. リポジトリの **Settings → Pages** で **Deploy from a branch → main → / (root)** を選んで **Save**。ブランチ名が違うときは、ファイルを置いたブランチを選びます。
4. 同じ Pages 画面に表示された **https://** の公開URLを、2台で開きます。GitHubのコード閲覧画面やダウンロードしたHTMLを直接開く方法では、同じリンクでの接続を試せません。

参考 [GitHub Pages の公開元を設定する](https://docs.github.com/ja/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 使う

1. 最初は両方を同じWi-Fiにつなぎます。パソコンが有線でも、同じローカルネットワーク上なら試せます。
2. 送る端末で **画面を送る → 招待コードを作る**。
3. 送る端末に「招待の準備ができました」と出たら、見る端末でQRを読むか、公開URLを開いて **画面を見る** に切り替え、16文字のコードを入力します。iPhone・iPadからPCに送る場合は、PCでコードを入力するか、送る側で「招待リンクをコピー」してPCに送ります。
4. 送る側で **許可して画面を共有** を押し、ブラウザやOSの表示に従って共有対象を選びます。見る側で映像が出たら **全画面** を使えます。
5. 終わったらどちらかで **接続を終了**。送る端末のブラウザやOSにある共有停止操作でも終了できます。

Windowsで送るならChromeまたはEdgeを使います。iPadとiPhoneの間でも、片方を送信側、もう片方を受信側にして使う設計です。iPhone・iPadで送る場合は Safari 27 以降が目安です。共有対象の選択肢や、ほかのアプリに切り替えた後の動作は端末とOSに依存します。見る側は画面取得APIを使わないため、Safari 27より前の環境でもWebRTCが使えれば受信できます。音声は送る側でチェックを入れ、ブラウザが選んだ共有元の音声を提供できる場合に限って届きます。

参考 [画面取得APIの対応表](https://caniuse.com/mdn-api_mediadevices_getdisplaymedia)

## かくつき・通信の途切れ

- 送る端末の「画質」は共有中に切り替えられます。「自動」は720pを目安にし、「安定優先」は480pを上限の目安にします。「高画質」は文字を読みやすくするため1080pを目安にします。いずれも通信や処理の負荷に応じて画質を下げ、回復を確認してから上げます。
- 送る端末のプレビューは初期状態では非表示です。送る側でも映像を確認したいときは「送信プレビューを表示」を押します。
- QR・接続コードでの共有中に通信が途切れると、開いている同じ相手へ最大1分ほど再接続を試します。画面共有自体をブラウザやOSが終了した場合や、ページを閉じたり更新したりした場合は、新しく招待を作ってください。
- 映像欄には、ブラウザから経路の情報が得られる場合に「直接接続」か「中継接続」を表示します。表示は実際に使っている通信経路です。
- 手動接続では、短い切断からの復帰を待ちます。接続が完全に切れた場合は、共有画面を選び直さずに「新しい招待コードを作る」からコードを交換できます。

## QRでつながらないとき

QRコードには、ランダムな接続コード付きの招待リンクが入っています。QRはブラウザ内で生成します。QRモードでは、公開の PeerServer Cloud が2台をつなぐための接続情報を取り次ぎます。映像はWebRTCで暗号化して転送し、直接接続できない場合は中継を使うことがあります。再接続では最初に接続した同じ閲覧セッションにのみ映像を送り、別の端末が開いた場合は改めて招待が必要です。このサイトには録画・保存機能や、接続相手の本人確認機能はありません。招待リンクは自分の端末や信頼できる相手だけに渡してください。

公開の接続サービスを使わない場合は、両方で **手動（接続サービスなし）** を選びます。

1. 送る側で画面を選び、生成された長い「招待コード」を見る側に送ります。
2. 見る側でコードを貼り付け、生成された「応答コード」を送る側に返します。
3. 送る側で「応答コード」を貼り付けて **コードを読み込む** を押します。

手動接続は2台が直接通信できるローカルネットワーク向けです。ゲストWi-Fi、VPN、ファイアウォール、ブラウザのプライバシー設定によってはQR・手動ともに接続できないことがあります。招待リンクやコードは、映像を見せる相手にだけ渡してください。
